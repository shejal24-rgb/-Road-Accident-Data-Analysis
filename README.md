
# 🚦 Road Accident Data Analysis

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Pandas](https://img.shields.io/badge/Pandas-Data_Analysis-purple)
![NumPy](https://img.shields.io/badge/NumPy-Numerical_Analysis-blue)
![Matplotlib](https://img.shields.io/badge/Matplotlib-Visualization-orange)
![Seaborn](https://img.shields.io/badge/Seaborn-EDA-green)

## 📌 Project Overview

This project focuses on analyzing road accident data using Python.

The objective is to explore accident severity, city-wise accident patterns, weather conditions, road types, vehicle categories and time-based accident trends.

## 🎯 Project Objectives

- Analyze road accident patterns.
- Identify accident severity levels.
- Compare city-wise accidents.
- Explore weather-related accident patterns.
- Analyze vehicle-wise accidents.
- Identify accident-prone time periods.
- Study monthly accident trends.
- Understand casualty distribution.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Structure

```text
Road-Accident-Analysis/
│
├── road_accidents.csv
├── road_accident_analysis.py
└── README.md
```

## 📊 Analysis Performed

1. Data Loading and Exploration
2. Data Cleaning and Preprocessing
3. Accident Severity Analysis
4. City-wise Accident Analysis
5. Weather Condition Analysis
6. Vehicle-wise Accident Analysis
7. Time-based Accident Analysis
8. Monthly Accident Analysis
9. Casualty Analysis

## 📈 Visualizations

- Accident Severity Distribution
- City-wise Road Accidents
- Weather-wise Accident Distribution
- Vehicle-wise Accident Analysis
- Accidents by Time Period
- Monthly Accident Analysis
- Average Casualties by Road Type

## 💡 Key Insights

The project helps identify:

- Cities with the highest recorded accidents.
- Most frequently recorded accident severity.
- Weather conditions associated with recorded accidents.
- Vehicle types involved in more accidents.
- Time periods with higher accident counts.
- Monthly accident patterns.
- Average casualties across road types.

## ⚙️ Installation

```bash
pip install pandas numpy matplotlib seaborn
```

## ▶️ How to Run

```bash
python road_accident_analysis.py
```
